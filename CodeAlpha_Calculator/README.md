# CodeAlpha Calculator

A simple and modern calculator web app built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Decimal support
- Percentage calculations
- Clear and backspace buttons
- Keyboard support for faster input
- Responsive, polished user interface

## How to Run

Open the project folder in your browser and load the index.html file, or serve the folder with a simple local server.
You can  also view this project in a browser using Live Server from your code editor.

## Project Structure

- index.html - Main structure of the calculator UI
- style.css - Styling and responsive layout
- script.js - Calculator logic and keyboard interaction

## Technologies Used

- HTML
- CSS
- JavaScript
