# Neelam Latif Portfolio

A clean and responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Overview

This project showcases:
- About section
- Skills section
- Projects section
- Resume section
- Contact section

It includes smooth scrolling, animated section reveals, hover effects, a theme toggle, mobile navigation, and project detail buttons.

## Files

- index.html — Main structure of the website
- style.css — Styling and responsive layout
- script.js — Interactivity such as navigation, animations, filters, and form handling
- resume.txt — Resume content for download

## How to View

You can view this project in a browser using Live Server from your code editor.

If you prefer to run it manually, open the project folder in a browser or use a simple local server.

## Customization

You can update the content in index.html to reflect your own details, projects, and contact information.
