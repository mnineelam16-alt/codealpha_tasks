# Image Gallery

A simple image gallery web page built with HTML, CSS, and JavaScript.

## Features
- Responsive layout
- Image thumbnails and lightbox-style viewing
- Clean and minimal styling

## Files
- index.html - Main page structure
- style.css - Styling for the gallery
- script.js - Gallery interactions

## How to Run
Open index.html in your browser to view the gallery.
You can also view this project in a browser using Live Server from your code editor.
